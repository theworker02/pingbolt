# pingbolt

Ping lightweight bolt statistics from stdin samples.

**Site:** https://theworker02.github.io/pingbolt/

## Install / run

```bash
git clone https://github.com/theworker02/pingbolt.git
cd pingbolt
node src/cli.js
node --test
```
